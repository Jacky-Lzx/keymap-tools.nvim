*keymap-tools.txt*       Bottom-right hints and executable mapping picker

Requires Neovim 0.10+. selection-tools.nvim is needed only for the picker.

SETUP                                                   *keymap-tools-setup*
>
  local tools = require("keymap_tools")
  tools.setup({
    defer = true,
    hints = { enabled = true, delay = 200, operators = true },
    window = { width = 80, height = 16, columns = 2, border = "rounded" },
    picker = {},
    showkeys = { enabled = false },
    presets = true,
    providers = { registers = true, marks = true, spelling = { suggestions = 20 } },
  })
  vim.keymap.set({ "n", "x" }, "<leader>?", tools.pick,
    { desc = "Choose and execute buffer keymap" })
<
Set mapleader before registration. Setup creates no global picker shortcut.
Automatic prefix rules use hints.triggers, a list of {prefix=...,modes={...}}.
Defaults: leader, localleader, g, z, [, ], C-w in n/x/o. Lists replace defaults,
including an empty list. hints.operators controls ModeChanged operator hints.
Provider prefixes are controlled by provider options, subject to hints.enabled.
Trigger modes are n/x/o/i/c. Disable competing hint plugins on those prefixes.

defer=true delays an early setup until VimEnter, before the first input. The
default is false (synchronous setup). Explicit show/pick/refresh activate pending
setup immediately; reconfiguring an active engine is always synchronous.
With lazy.nvim, use event="VimEnter" and defer=true, and register selection-tools
separately: only pick() needs it, so hints do not require an eager dependency.
register() loads metadata storage only; list() does not initialize the hint engine
or UI. Hint rendering loads on first display.

USAGE                                                   *keymap-tools-usage*

Pause after a prefix to see next keys; after d/c/y/gU/g@ for motions/textobjects.
Type i/a to narrow textobjects, BS to go up, Esc/C-c to cancel. C-d/C-u pages long
lists unless a candidate uses that key. Unknown sequences replay normally.
Counts, registers, custom operators, native dot-repeat and undo are retained.
Hints default to two columns, filled top to bottom and then left to right.
Narrow windows fall back to one column; window.columns=1 forces one column.
Space appears as ␣. Scrolling keys sit on the bottom-left border and the candidate
range on the bottom-right border. Very narrow borders keep only the range;
borderless hints use a content footer.

" shows registers; C-r shows them in Insert/command-line mode. Clipboard contents
are not read unless providers.registers.clipboard=true. '/`/g'/g` shows marks;
z= shows spelling suggestions; a numeric prefix such as 1z= keeps native behavior.

The picker searches effective mappings for the current mode/buffer. Type to
filter, C-n/C-p to navigate, CR to execute, Esc to cancel. The source window and
Visual range are restored; changed mappings are rejected before replay.

COMMAND                                                 *:KeymapTools*

:KeymapTools [pick]      Search and execute actual effective mappings.
:KeymapTools show        Open an interactive root hint.
:KeymapTools hide        Close a hint.
:KeymapTools refresh     Refresh automatic prefix triggers.
:KeymapTools showkeys    Toggle the recent-key screencast.
:KeymapTools showkeys enable / disable / toggle
                        Explicit screencast listener actions.

KEY SCREENCAST                                          *keymap-tools-showkeys*
>
  require("keymap_tools").setup({
    showkeys = {
      enabled = false,
      timeout = 3, -- Seconds of inactivity
      maxkeys = 5,
      show_count = false,
      excluded_modes = {}, -- e.g. { "i", "c", "t" }
      position = "bottom-right",
      keyformat = { ["<Space>"] = "␣", ["<C>"] = "Ctrl" },
      winopts = { border = "single", zindex = 60 },
      winhl = "Normal:NormalFloat,FloatBorder:FloatBorder",
    },
  })
  local cast = require("keymap_tools").showkeys
  vim.keymap.set("n", "<leader>uk", cast.toggle, { desc = "Toggle key screencast" })
  cast.enable()
  cast.disable()
  print(cast.is_enabled())
<
Built-in alternative to nvzone/showkeys; no dependency or automatic shortcut.
Default is disabled. enabled=true starts listening during setup, independently
of defer/hints.enabled. Actions do not activate deferred hints or the picker.
Timeout closes the window but leaves listening enabled. disable removes the
listener, timer, window, buffer and autocmds. Setup resets history and reapplies
enabled; tab changes clear history. The screencast preserves focus, avoids
overlapping hints, and retains the newest entries on narrow screens.

Positions: top-left/top-center/top-right/bottom-left/bottom-center/bottom-right.
show_count combines consecutive repeats (e.g. 3 j). maxkeys limits entries.
excluded_modes replaces the whole list; matches an exact mode or a one-letter
prefix (i also matches ic). keyformat merges with default Unicode labels, using
keytrans() notation. Empty labels hide keys. Complete chords take precedence;
modifier labels use <C>/<M>/<S>/<D>. winopts accepts border and zindex only.
Mouse events and mapping-generated keys are ignored; hint replay is not counted
twice. Highlights: KeymapToolsShowkeysActive / KeymapToolsShowkeysInactive.

Migration: move showkeys options into setup().showkeys, replace ShowkeysToggle
with KeymapTools showkeys and remove the old plugin spec. Default maxkeys is 5;
labels use standard Unicode rather than Nerd Font glyphs.

REGISTRATION                                            *keymap-tools-register*
>
  local handle = require("keymap_tools").register("mini.ai", {
    modes = { "o", "x" },
    groups = { { prefix = "i", label = "Inside" } },
    hints = { { keys = "if", desc = "Inside function" } },
  })
  handle:replace({ modes = { "o", "x" }, hints = {
    { keys = "if", desc = "Inside function" },
  } })
  handle:dispose()
<
Real mappings belong to vim.keymap.set(). Registration creates metadata only.
A source ID has one registration per buffer scope plus one global registration.
Omit buf for global; buf=0 captures the current buffer. Buffer wipe releases its
registrations even before setup. Per-entry modes override registration modes.

Conflict order: buffer before global, higher priority before lower, newest before
older. Disposing an override reveals retained lower-priority sources. Repeated
registration of the same source/scope invalidates the old handle. replace()
validates before atomically replacing all data while retaining source/buffer.
dispose() is idempotent and cannot remove a newer registration.

label/desc/when/hidden may be functions receiving ctx: buf, win, mode, prefix,
operator, count, register. win is absent for a buffer with no display window.
Use ctx rather than implicit current-window state. Callback contexts and query
rows are detached copies. Values are evaluated on query/open; callback failures
are returned in query diagnostics. Group hidden=true also hides descendants.

TOGGLES                                                 *keymap-tools-toggles*
>
  require("keymap_tools").register("window.wrap", {
    toggles = {
      { keys = "<leader>tw", name = "Wrap", get = function(ctx)
        if ctx.win then
          return vim.api.nvim_get_option_value("wrap", { win = ctx.win })
        end
      end },
    },
  })
<
Each toggle requires keys, name (string or context callback), and get(ctx).
get returns true (enabled), false (disabled), or nil (unknown/unavailable).
The shared description is Disable <name>, Enable <name>, or Toggle <name>.
Rows expose toggle={name=...,state=...}; unknown state has no state value.
A toggle uses kind="hint", or decorates kind="mapping" if a real map exists.
Only actual mappings are executable; the picker replays the owner's keys.

The feature owns its state, mapping and switching logic. There is no setter,
mapping installation, state cache, polling, or automatic feature integration.
Registration and trigger discovery never call get. Queries/opening read fresh
state; open displays are snapshots. Reopen to see subsequent external changes.
Getter errors or non-boolean/non-nil results show unknown state and add a get
diagnostic to info.errors. Return nil for an expected unavailable state.

Toggles support modes/when/hidden and all registration scopes, priorities and
handles. Hints/toggles compete for one metadata slot; an ordinary hint override
removes toggle state. Within one registration, toggles win over hints.
Use ctx.buf/ctx.win for local state. For legacy implicit-window getters, guard
ctx.win and use nvim_win_call. Avoid loading lazy features from status getters;
use package.loaded or register after the owner loads. Session settings such as
inlay hints should read the session-wide owner state. See README for examples.

QUERY AND DISPLAY                                       *keymap-tools-api*
>
  local tools = require("keymap_tools")
  local items, info = tools.list({
    buf = 0, mode = "n", prefix = "<leader>g", scope = "effective",
    kinds = { "mapping", "hint", "group", "provider", "choice" },
  })
  tools.show({ prefix = "<leader>g" })
  tools.pick({ scope = "buffer", layout = { width = 0.7 } })
  tools.hide()
  tools.refresh()
<
list() does not initialize UI. Rows have keys (canonical notation), kind, source,
metadata_source, scope, buf, mode, desc, hidden and executable. Only actual
mapping rows are executable. Toggles additionally expose toggle.name and
toggle.state (boolean, or absent for unknown). Empty groups are omitted.
Plug targets require plugs=true; hidden rows require include_hidden=true.
info contains context and errors (source/field/message). Internal keycodes/map
dictionaries stay private.

Query scopes: effective resolves local overrides; global reads global data,
including shadowed global maps; buffer reads only buffer data. Actual mappings
have source="neovim"; metadata uses registration IDs; native rows use builtin:
IDs. Pass win or buf to inspect another source. At an exact provider prefix,
choice rows use the source window; no choices are generated without a window.

The picker queries only actual effective mappings. Its scope filter restricts
that effective set, excluding shadowed global maps. show()/pick() operate on the
active source window; list() can inspect another window without changing focus.

CONFIGURATION                                           *keymap-tools-options*

hints.enabled/ delay/ operators/ triggers    Automatic hint behavior.
window.width/ height/ columns/ border       Hint appearance; width is total width.
picker                                      selection-tools picker options.
showkeys                                    Optional recent-key screencast.
presets                                     true/false or individual catalog flags.
providers                                   registers/marks/spelling options.

Preset flags: motions/navigation/windows/folds/textobjects. Provider options
accept false or {enabled=false}; spelling.suggestions is 1..62 (default 20).
No add()/get_keymaps() or positional registration API remains. Use register(),
list(), hints/window options and explicit user key bindings.

Highlights: KeymapToolsNormal, KeymapToolsBorder, KeymapToolsKey, KeymapToolsGroup.
See README.md for installation and validation details.
