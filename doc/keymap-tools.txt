*keymap-tools.txt*       Bottom-right hints and executable mapping picker

Requires Neovim 0.10+. selection-tools.nvim is needed only for the picker.

SETUP                                                   *keymap-tools-setup*
>
  local tools = require("keymap_tools")
  tools.setup({
    hints = { enabled = true, delay = 200, operators = true },
    window = { width = 48, height = 16, border = "rounded" },
    picker = {},
    presets = true,
    providers = { registers = true, marks = true, spelling = { suggestions = 20 } },
  })
  vim.keymap.set({ "n", "x" }, "<leader>?", tools.pick,
    { desc = "Choose and execute buffer keymap" })
<
Set mapleader before registration. Setup creates no global picker shortcut.
Automatic prefix rules use hints.triggers, a list of {prefix=...,modes={...}}.
Defaults: leader, localleader, g, z, [, ], C-w in n/x/o. Lists replace defaults,
including an empty list. hints.operators controls ModeChanged operator hints.
Provider prefixes are controlled by provider options, subject to hints.enabled.
Trigger modes are n/x/o/i/c. Disable competing hint plugins on those prefixes.

USAGE                                                   *keymap-tools-usage*

Pause after a prefix to see next keys; after d/c/y/gU/g@ for motions/textobjects.
Type i/a to narrow textobjects, BS to go up, Esc/C-c to cancel. C-d/C-u pages long
lists unless a candidate uses that key. Unknown sequences replay normally.
Counts, registers, custom operators, native dot-repeat and undo are retained.

" shows registers; C-r shows them in Insert/command-line mode. Clipboard contents
are not read unless providers.registers.clipboard=true. '/`/g'/g` shows marks;
z= shows spelling suggestions; a numeric prefix such as 1z= keeps native behavior.

The picker searches effective mappings for the current mode/buffer. Type to
filter, C-n/C-p to navigate, CR to execute, Esc to cancel. The source window and
Visual range are restored; changed mappings are rejected before replay.

COMMAND                                                 *:KeymapTools*

:KeymapTools [pick]      Search and execute actual effective mappings.
:KeymapTools show        Open an interactive root hint.
:KeymapTools hide        Close a hint.
:KeymapTools refresh     Refresh automatic prefix triggers.

REGISTRATION                                            *keymap-tools-register*
>
  local handle = require("keymap_tools").register("mini.ai", {
    modes = { "o", "x" },
    groups = { { prefix = "i", label = "Inside" } },
    hints = { { keys = "if", desc = "Inside function" } },
  })
  handle:replace({ modes = { "o", "x" }, hints = {
    { keys = "if", desc = "Inside function" },
  } })
  handle:dispose()
<
Real mappings belong to vim.keymap.set(). Registration creates metadata only.
A source ID has one registration per buffer scope plus one global registration.
Omit buf for global; buf=0 captures the current buffer. Buffer wipe releases its
registrations even before setup. Per-entry modes override registration modes.

Conflict order: buffer before global, higher priority before lower, newest before
older. Disposing an override reveals retained lower-priority sources. Repeated
registration of the same source/scope invalidates the old handle. replace()
validates before atomically replacing all data while retaining source/buffer.
dispose() is idempotent and cannot remove a newer registration.

label/desc/when/hidden may be functions receiving ctx: buf, win, mode, prefix,
operator, count, register. win is absent for a buffer with no display window.
Use ctx rather than implicit current-window state. Callback contexts and query
rows are detached copies. Values are evaluated on query/open; callback failures
are returned in query diagnostics. Group hidden=true also hides descendants.

QUERY AND DISPLAY                                       *keymap-tools-api*
>
  local tools = require("keymap_tools")
  local items, info = tools.list({
    buf = 0, mode = "n", prefix = "<leader>g", scope = "effective",
    kinds = { "mapping", "hint", "group", "provider", "choice" },
  })
  tools.show({ prefix = "<leader>g" })
  tools.pick({ scope = "buffer", layout = { width = 0.7 } })
  tools.hide()
  tools.refresh()
<
list() does not initialize UI. Rows have keys (canonical notation), kind, source,
metadata_source, scope, buf, mode, desc, hidden and executable. Only actual
mapping rows are executable. Empty groups are omitted. Plug targets require
plugs=true; hidden rows require include_hidden=true. info contains context and
errors (source/field/message). Internal keycodes/map dictionaries stay private.

Query scopes: effective resolves local overrides; global reads global data,
including shadowed global maps; buffer reads only buffer data. Actual mappings
have source="neovim"; metadata uses registration IDs; native rows use builtin:
IDs. Pass win or buf to inspect another source. At an exact provider prefix,
choice rows use the source window; no choices are generated without a window.

The picker queries only actual effective mappings. Its scope filter restricts
that effective set, excluding shadowed global maps. show()/pick() operate on the
active source window; list() can inspect another window without changing focus.

CONFIGURATION                                           *keymap-tools-options*

hints.enabled/ delay/ operators/ triggers    Automatic hint behavior.
window.width/ height/ border                Hint appearance.
picker                                      selection-tools picker options.
presets                                     true/false or individual catalog flags.
providers                                   registers/marks/spelling options.

Preset flags: motions/navigation/windows/folds/textobjects. Provider options
accept false or {enabled=false}; spelling.suggestions is 1..62 (default 20).
No add()/get_keymaps() or positional registration API remains. Use register(),
list(), hints/window options and explicit user key bindings.

Highlights: KeymapToolsNormal, KeymapToolsBorder, KeymapToolsKey, KeymapToolsGroup.
See README.md for installation and validation details.
